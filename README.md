lsp for view.tree

## Install

```bash
npm install -g  view-tree-lsp@latest
```

## Потоки данных

- Outline (`textDocument/documentSymbol`): класс, под ним свойства в порядке дерева, под-виды вложены. В `detail` направление: `<= имя` читает из хозяина, `<=> имя` двусторонняя, `=> имя` отдаёт наружу, `^` наследует.
- Inlay hints (`textDocument/inlayHint`): в конце строки с `<=` или `<=>` пишется, откуда значение: `← $класс.свойство` или `← перекрыто в app.view.ts`, если метод есть в соседнем `.view.ts`. В Zed включаются настройкой `"inlay_hints": { "enabled": true }`.
- Code action «Поток модуля» (команда `viewtree.flow`): берёт ближайший `<модуль>/-/web.deps.json`, разворачивает порядок бандла от приложения к листьям и пишет `<модуль>/-/flow.md` со ссылками на файлы и зависимостями каждого модуля. Без `web.deps.json` просит собрать модуль.
